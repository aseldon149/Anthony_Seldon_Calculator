# Anthony Seldon - Calculator

## Project Description

This project is a C# console-based calculator developed
for the SDC220 course project.

The application allows users to perform mathematical
calculations, work with multiple numbers, and store and
recall values using calculator memory.

## Features

- Addition, subtraction, multiplication, and division.
- Calculations using multiple numbers.
- Decimal number support with two decimal places.
- Division-by-zero handling.
- Memory storage for up to 10 values.
- Memory recall, display, and clearing.
- Input validation and exception handling.
- Menu-driven console interface.

## Technologies Used

- C#
- .NET
- Visual Studio Code

## How to Run

1. Open the project folder in Visual Studio Code.
2. Open the integrated terminal.
3. Run `dotnet build`.
4. Run `dotnet run`.
5. Follow the calculator menu.
